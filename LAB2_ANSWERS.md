Question 2

`--backend-store-uri` specifies where MLflow stores run metadata. Here it uses `sqlite:///mlflow.db`. `--default-artifact-root` specifies where run artifacts such as trained models are stored, here `./mlruns`. Metadata includes parameters, metrics, run IDs, and run information, while artifacts are actual files such as the saved model.

Question 5

`log_param` records fixed values chosen before training, such as learning rate, batch size, epochs, and dataset. `log_metric` records values produced during training, such as loss and accuracy. Metrics use a step because their values can change at each epoch, while a parameter stays fixed for the whole run.

Question 6

The run page in the MLflow UI shows the parameters and metrics, and metric values can be viewed as charts. The trained model is available under the run's `artifacts/model` section. With `--default-artifact-root ./mlruns`, the model artifact is stored inside the local `mlruns` directory for that experiment and run.
